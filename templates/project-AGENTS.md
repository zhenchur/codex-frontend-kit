# Project frontend instructions

Заполни команды и ссылки для конкретного проекта. Этот файл можно скопировать в
корень репозитория как `AGENTS.md`; установщик сам его в проекты не добавляет.

- Используй текущий стек и менеджер пакетов, определённые package.json и lockfile.
- Укажи версию Node в `.nvmrc` и `package.json#engines`, если проект зависит от неё.
- Исходники: `src/`; геометрия и данные композиций должны быть отделены от UI.
- Ассеты сохраняй локально; ссылки на дизайн и принятые параметры фиксируй в README.
- Предпросмотр, экспорт и проверки используют одну модель данных, без параллельных копий геометрии.
- Перед завершением запускай команды, которые реально есть в package.json. Для проекта Р.О.С.Т.: `npm test`, `npm run build`.
- Проверь изменённое поведение в браузере, консоль, паузу/скорость/направление и reduced motion, когда они затронуты.
- Перед передачей другой машине проверь чистую установку зависимостей и сборку.
- Не меняй согласованные эффекты и дизайн вне объёма текущего запроса.
