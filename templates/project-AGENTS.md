# Project frontend instructions

Адаптируй файл под репозиторий перед сохранением как `AGENTS.md`: укажи реальные
команды из package.json, расположение компонентов, токенов и ссылки на дизайн.
Установщик не добавляет этот шаблон в проекты автоматически.

- Сохраняй стек и менеджер пакетов из package.json и lockfile. Для нового React-фронтенда базовый выбор — React + TypeScript + Vite, обычный CSS с БЭМ, GSAP; Lenis добавляется для требуемой плавной прокрутки.
- Версию Node и команды dev/build/typecheck/lint/test бери из текущего проекта. Не придумывай npm-скрипты и не обновляй зависимости только ради совпадения с шаблоном.
- Компоненты — `ProductCard.tsx`, хуки — `useCardMotion.ts`, функции и переменные — camelCase. Типизируй props, обработчики и DOM refs.
- CSS: `product-card`, `product-card__title`, `product-card--featured`, `product-card__title--muted`. Модификатор используй вместе с базовым классом. Глобальные токены/reset держи отдельно от стилей компонентов; применяй имеющиеся CSS custom properties.
- Сохраняй обычный CSS/БЭМ, если он принят проектом. Не подключай Tailwind или CSS Modules без запроса; не мигрируй существующий другой стиль организации CSS.
- Ассеты сохраняй локально; реализуй точную указанную Figma-ноду в существующей оболочке. Не меняй согласованные дизайн и эффекты вне текущего запроса.
- GSAP регистрируй в общем модуле. Анимации компонентов создавай в scoped `useGSAP`, очищай обработчики, таймеры, observers и отложенные действия. Для зависимостей, пересоздающих анимацию, используй `revertOnUpdate`.
- У Lenis один владелец основного scroller. При GSAP ticker — `autoRaf: false`, `lenis.raf(time * 1000)`, один callback; очистка удаляет его и подписки, затем уничтожает экземпляр. Не запускай второй RAF.
- Сохраняй reduced motion, нативный touch-скролл, клавиатурную навигацию, фокус и якоря. Пересчитывай ScrollTrigger после реального изменения layout.
- Проверь изменённый интерфейс в браузере: размеры из макета, консоль, клавиатуру, resize и затронутую анимацию. Перед передачей проверь чистую установку зависимостей и production build; перечисли только выполненные проверки.
