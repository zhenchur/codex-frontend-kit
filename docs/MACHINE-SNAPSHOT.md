# Что фактически было на исходной машине

Проверено 21 октября 2026 года. Значения ниже извлечены из разрешённого набора
полей локального config.toml; весь конфиг в репозиторий не копировался.

| Настройка | Найденное значение | Перенос |
| --- | --- | --- |
| model | `gpt-6-astra` | optional профиль `frontend.config.toml` |
| model_reasoning_effort | `ultra` | тот же профиль |
| service_tier | `priority` | тот же профиль |
| windows.sandbox | `elevated` | не переносится между ОС автоматически |
| features.js_repl | `false` | записано здесь; инструменты устанавливает приложение |
| features.memories | `true` | записано здесь; память и история не копируются |
| memories.generate_memories | `true` | записано здесь |
| memories.use_memories | `true` | записано здесь |
| пользовательский AGENTS.md | пустой, 0 байт | исходный пустой файл сохранён как `profile/AGENTS.original.md` |
| rules/default.rules | 3 правила allow | только переносимое `npm run dev` отдельно и opt-in |

Два оставшихся разрешения запуска привязаны к абсолютным Windows-путям: проверка
localhost PowerShell-командой и запуск dev-сервера через cmd.exe. Они не включены
в устанавливаемые правила. Sandbox/approval_policy из активного чата не являются
переносимыми настройками пользователя и не записаны в профиль.

`profile/AGENTS.md` — заново оформленные рабочие соглашения. Они покрывают точную
Figma-ноду, сохранение стека и не затронутой анимации, GSAP cleanup/reduced motion,
визуальную проверку и воспроизводимую передачу проекта. Это явно новая часть
комплекта, а не утверждение, что такие строки уже были в пустом локальном файле.

В config.toml также присутствовали параметры desktop-интерфейса, доверенные
локальные проекты, MCP/node_repl runtime-пути и список плагинов. Они не копируются:
на другой машине пути, разрешения и доступность интеграций нужно настроить заново.
Релевантные плагины перечислены в `plugins.json`.

`.gitattributes` задаёт `* -text`: Git сохраняет точные байты файлов без
нормализации LF/CRLF при коммите и клонировании на Windows, Linux и macOS.
Это сохраняет копии исходных навыков 1:1 и позволяет проверять их SHA-256
из `manifest.json` независимо от локального `core.autocrlf`.
