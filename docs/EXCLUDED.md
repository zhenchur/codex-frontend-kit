# Что не переносится

- `auth.json`, ключи API, OAuth-состояние, cookies, keychain и профили браузеров.
- Сессии, логи, SQLite-базы, память с историей проектов, clipboard, вложения и private data других задач.
- Абсолютные пути исходной машины, trust_level для старых папок, Windows pipes и runtime-бинарники Codex.
- `notify` и другие запускаемые при событиях команды, переменные среды внутренних инструментов.
- Разрешения sandbox и approvals; установщик не назначает `danger-full-access` или `never`.
- Системные и developer-инструкции продукта. Они поставляются текущей версией приложения, их нельзя воспроизвести пользовательским AGENTS.md.
- Кеш плагинов как исполняемая установка. Плагины, браузерные инструменты и коннекторы устанавливаются через приложение заново.

Проверка `npm run verify` ищет распространённые сигнатуры секретов и запрещённые
имена файлов, но не является доказательством отсутствия любого возможного секрета.
Комплект создан выборочным копированием только перечисленных навыков и allowlist
полей конфигурации. Посторонние данные не входят в его источники.
