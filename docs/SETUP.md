# Установка на новой машине

Основная команда находится в [README](../README.md). Она устанавливает весь переносимый комплект; ручное копирование файлов не требуется.

## Программы и подключения

| Что | Ссылка | Когда нужно |
| --- | --- | --- |
| Node.js 22.12+ с npm/npx | [Скачать Node.js](https://nodejs.org/en/download) | Для одной команды и разработки; проверена версия 24.12 |
| Приложение с Codex | [Установка приложения](https://learn.chatgpt.com/docs/app) | Установить и войти в свой аккаунт |
| Codex CLI | [Официальный CLI](https://learn.chatgpt.com/docs/cli) | По желанию, для работы через терминал |
| Figma и GitHub | [Официальный каталог плагинов](https://learn.chatgpt.com/docs/plugins) | Найти по имени, установить и подключить свой аккаунт |
| Git | [Скачать Git](https://git-scm.com/downloads) | Для клонирования и разработки; комплект устанавливается без Git |

После подключения Figma проверьте чтение нужной ноды, после подключения GitHub — доступ к репозиторию. Браузерные инструменты предоставляет приложение. [plugins.json](../plugins.json) перечисляет подключения, но не выдаёт доступ к аккаунтам и не заменяет установку плагина. Навыки Figma поставляются официальным плагином вместе с инструментами; вручную дублировать их в пользовательской папке не нужно.

## Что делает одна команда

1. npm получает публичный архив; `setup.mjs` проверяет его `manifest.json` до записей в профиль.
2. Устанавливает 11 навыков и их лицензии в `~/.agents/skills`.
3. Добавляет/обновляет помеченный блок правил в активном глобальном AGENTS. Если есть непустой `AGENTS.override.md`, используется он; остальной текст сохраняется.
4. Копирует `frontend.config.toml` и `rules/frontend-kit.rules`. Правило разрешает `npm run dev` в режимах Codex, поддерживающих пользовательские command rules; sandbox и политики организации продолжают действовать.
5. Перед заменой отличающихся файлов комплекта создаёт копии в `~/.codex/frontend-kit-backups`. Повторная установка одинаковой версии не меняет файлы.

При заданном `CODEX_HOME` настройки, AGENTS, правила и копии хранятся там. Skills остаются в пользовательской `~/.agents/skills`. Флаги `--home` и `--codex-home` с абсолютными путями предназначены для изолированного теста или выбранного профиля.

Существующие одноимённые навыки обновляются с резервной копией. Если вы вручную установили ещё одну копию того же навыка через плагин или старую папку навыков, оставьте один источник: Codex не объединяет одинаковые имена. Установщик не удаляет чужие плагины и папки.

## Профиль модели

В `frontend.config.toml` сохранены три значения: `model = "gpt-6-astra"`, `model_reasoning_effort = "ultra"`, `service_tier = "priority"`. Они не активируются автоматически и не меняют обычную модель приложения. Рабочие правила и навыки загружаются независимо от модели.

В CLI с поддержкой отдельных профилей используйте `codex --profile frontend`. В приложении при необходимости выберите доступную модель и уровень рассуждений в настройках чата. Наличие модели и уровня сервиса зависит от аккаунта. [Формат профилей](https://learn.chatgpt.com/docs/config-file/config-advanced).

## После установки

Начните новый чат в папке проекта. Codex должен видеть frontend-правила и навык `frontend-react-workflow`. Для нового проекта задайте задачу обычным текстом; для существующего он сначала прочитает его правила и сохранит установленный стек. Если навыки не появились, перезапустите приложение. [Обнаружение навыков](https://learn.chatgpt.com/docs/build-skills), [приоритет AGENTS](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

Основной `config.toml`, токены, историю, доверенные пути и разрешения машины комплект не переносит. Полный список — в [EXCLUDED.md](EXCLUDED.md).
